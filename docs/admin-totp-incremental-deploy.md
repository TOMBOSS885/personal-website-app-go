# 管理员 2FA 增量更新

本压缩包用于已部署本站的 PHP 虚拟主机。更新包只包含前端静态文件、API 文件和新增迁移，不包含生产配置和上传目录。

升级后，后台“账号安全”可以开关“进入后台时需要 2FA 验证”。开启后需用手机身份验证器扫码绑定；之后每次登录后台都要输入动态验证码。关闭时必须再输入当前验证码。

## 部署

1. 在虚拟主机面板备份网站文件和当前 MySQL 数据库。
2. 打开 SQL 管理面板，选中本站实际使用的数据库，导入 `migrations/019_admin_totp.sql`。该迁移可重复执行；不要跳过这一步。
3. 打开在线文件管理，进入能看到现有 `index.html`、`assets`、`api`、`app`、`config`、`uploads` 的运行目录。
4. 上传本 ZIP 并解压到当前目录，允许覆盖同名文件。
5. 不要删除或覆盖服务器已有的 `config/`、`uploads/` 和伪静态配置；TOTP 密钥加密依赖现有 `config/config.php` 的 `setup_key`。
6. 删除服务器上的更新 ZIP，并在面板中清理 OPcache 或重载 PHP（如有该功能）。
7. 浏览器强制刷新后访问 `/api/health`，应返回 `schema: "019"`。

## 开启二步验证

1. 使用原管理员密码登录后台。
2. 打开“账号安全”→“登录二步验证（2FA）”。
3. 打开右侧开关，或直接输入当前管理员密码后点击“开始绑定身份验证器”。
4. 用手机身份验证器扫描二维码；无法扫码时可复制页面显示的手工密钥。
5. 将身份验证器当前显示的 6 位验证码填入 6 个输入框，点击“确认并开启”。
6. 开启后退出并重新登录，密码正确后还会出现二步验证页面；只有输入动态码才能进入后台。

关闭二步验证时，必须在“账号安全”页面输入身份验证器当前的 6 位验证码。服务端会校验验证码、过期时间和已使用的时间窗口，前端隐藏按钮不是安全边界。

## 注意事项

- TOTP 密钥只在绑定流程中显示一次，并以 AES-256-GCM 加密后保存；加密密钥由 `config/config.php` 的 `app.setup_key` 派生。请勿更换或丢失 `setup_key`，否则已绑定的二步验证密钥无法解密。
- 登录挑战有效期 5 分钟，最多尝试 5 次；失败后必须重新输入密码。验证码允许前后各一个 30 秒时间窗口，以容忍手机和服务器轻微时钟偏差。
- 当前版本没有短信或备用恢复码。如果手机丢失，请在维护窗口内使用数据库备份恢复 `admin_account` 的 TOTP 字段，或由受信任的主机管理员按应急流程清空该账号的 `totp_secret_encrypted`、`totp_enabled`、`totp_last_counter` 和 `totp_confirmed_at` 后再重新绑定。
- 备份导出会随数据库一并备份加密后的 TOTP 字段；恢复前必须先确保目标库已导入 019 迁移并保留相同的 `setup_key`。

## 回滚

恢复本次上传覆盖的 `index.html`、`assets/`、`api/index.php`、`app/` 文件即可。数据库新增列建议保留；若必须回滚功能，将 `admin_account` 的 `totp_enabled` 设为 0 并清空 `totp_secret_encrypted`、`totp_last_counter`、`totp_confirmed_at`。不要直接删除列，除非已确认完成数据库备份。
