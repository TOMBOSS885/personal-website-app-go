# 管理入口安全后缀迁移说明

后台入口后缀存储在数据库中，可在“后台 -> 账号安全 -> 后台安全地址”直接修改。`config.php` 中的 `admin_path_suffix` 只用于首次安装和数据库设置尚未初始化时的兼容回退，日常修改不需要操作服务器文件。

## 更新现有网站

1. 在 phpMyAdmin 中选择网站数据库，导入补丁包里的 `migrations/005_admin_path_settings.sql`。
2. 将补丁 ZIP 上传到网站根目录并覆盖解压。补丁不会包含或覆盖 `config`、`uploads`、`setup.php` 和伪静态文件。
3. 使用更新前的后台地址登录，进入“账号安全”。
4. 在“后台安全地址”中输入新的随机后缀和当前管理员密码，然后保存。
5. 保存成功后页面自动跳转到 `https://你的域名/新后缀/account`。旧后缀立即失效，不会跳转或暴露新地址。

后缀必须为 8 到 64 位，只能使用英文大小写字母、数字、连字符 `-` 和下划线 `_`。不能使用 `blog`、`projects` 等公开路由名。推荐使用类似 `control-k8x4m2q7r9` 的随机值，并把新地址保存在密码管理器中。

## 安全迁移与恢复

迁移 SQL 只创建表，不预先写入后缀。因此单独导入 SQL 不会改变当前入口；升级后的旧网站会继续使用 `/admin/login`，第一次打开“账号安全”时系统才保存当前入口，然后允许从后台修改。

若忘记新地址，数据库记录位于：

```sql
SELECT admin_path_suffix FROM site_settings WHERE id = 1;
```

紧急恢复时可以在 phpMyAdmin 中将该值改成新的合法随机后缀，然后访问 `https://你的域名/该后缀/login`。不要删除或改坏这一行来尝试回退，因为数据库设置存在后会优先于 `config.php`。

本功能不需要修改 Nginx 或 Apache 伪静态规则。隐藏入口只是附加防护，管理员密码、Session 和 CSRF 校验仍然保留。
