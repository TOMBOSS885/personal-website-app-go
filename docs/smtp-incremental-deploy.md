# SMTP 邮件服务增量更新部署说明（PHP 虚拟主机）

本压缩包用于已部署本站的 PHP 虚拟主机。更新包只包含前端静态文件、API 文件和新增迁移，不包含生产配置和上传目录。

升级后的后台“导出完整备份”会加密保存数据库结构与全部数据（文章、项目、卡片、Live2D、账号、OAuth、SMTP、思维导图、日志等）、应用设置和 `uploads/` 文件，可在数据库为空或现有数据库上通过“导入完整备份”恢复。

操作日志采用数量上限策略，始终只保留最近 200000 条；新增日志或打开日志列表时会自动删除更早记录。

## 部署

1. 在虚拟主机面板备份网站文件和当前 MySQL 数据库。
2. 打开 SQL 管理面板，选中本站实际使用的数据库，导入 `migrations/017_smtp_email_verification.sql`。迁移只新增 `mail_settings` 与 `email_verification_codes` 两张表。
3. 打开在线文件管理，进入能看到现有 `index.html`、`assets`、`api`、`app`、`config`、`uploads` 的运行目录。
4. 上传本 ZIP 并解压到当前目录，允许覆盖同名文件。
5. 不要删除或覆盖服务器已有的 `config/`、`uploads/` 和伪静态配置；SMTP 密码加密密钥依赖现有 `config/config.php` 的 `setup_key`。
6. 删除服务器上的更新 ZIP，并在面板中清理 OPcache 或重载 PHP（如有该功能）。
7. 浏览器强制刷新后访问 `/api/health`，应返回 `schema: "017"`。

## 配置与验收

登录管理后台，打开“邮件服务”，填写 SMTP Host、端口、用户名、授权码、发件邮箱和安全连接方式，保存后发送测试邮件。注册邮箱验证开关默认关闭，确认测试邮件成功后再开启。

开启后，普通账号注册会要求邮箱验证码（10 分钟有效、60 秒重发限制）；登录和第三方登录不需要验证码。验证码只绑定注册邮箱和 `REGISTER` 场景，服务端强制校验，不能通过直接调用接口绕过。

## 回滚

恢复本次上传覆盖的 `index.html`、`assets/`、`api/index.php`、`app/` 文件即可。数据库表建议保留并关闭“注册邮箱验证码验证”；不要直接删除表，除非已确认完成数据库备份并接受手工回滚。
